Run the `x-conventions` skill before any convention-governed action: writing or editing code (ordering, function params, comments), naming a branch, writing a commit message or PR title/body, choosing formatting or lint tooling. It routes to `~/.config/agents/x-memory/index.md` and the project's `.agents/x-memory/index.md` — read only the page matching the topic. A repo's own AGENTS.md and history win over the global page.

Work symbol-first on TypeScript. Reach for the LSP (`lsp` tool, `xd://lsp`, or a language MCP such as `typescript-mcp`) before editing a symbol: definitions, references, hover, diagnostics, rename, code actions. Use `ast_edit` for structural codemods and `ast_grep` for structural search; text search and `edit` stay for literals, config, and non-code files. No need to ask first. Word completion: `action: "request"`, `query: "textDocument/completion"`, payload `{position:{character, line}, textDocument:{uri}}` (0-based; after a `.` add `context:{triggerCharacter:".", triggerKind:2}`); the server returns the whole scope unfiltered, so filter labels by the typed prefix.
